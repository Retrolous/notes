Define a cipher as follows:
``` haskell
encrypt :: String -> String -- type String = [Char]
encrypt xs = map (chr . succ . ord) xs -- consider if x is the max value in list of character codes
```

We could instead have implemented the above using three maps:
```haskell
encryptSlow :: String -> String
encryptSlow xs = (map chr . map succ . map ord) xs
```

### Map fusion

By using map fusion, the compiler can optimise the code from encryptSlow to encrypt. In general, this is possible because `map g . map f = map(g . f)` (eta-expansion + because Haskell is pure)

We can prove this by induction on the input.

### Filters
We've seen filters in list comprehensions:
```haskell
[x | x <- xs, p x]
```
We can write:
```haskell
evens :: [Int] -> [Int]
evens xs = [x | x <- xs, even x]
```
where `even :: Int -> Bool`

We can define a filter function:
``` haskell
filter :: (a -> Bool) -> [a] -> [a]
filter p [] -> []
filter p (x:xs) 
  | p x -> x : filter p xs
  | otherwise -> filter p xs
```

Some other useful functions:
``` haskell
any :: (a -> Bool) -> [a] -> bool
any p [] -> false
any p (x:xs) = p x || any p xs
```
...or alternatively:
``` haskell
any :: (a -> Bool) -> [a] -> bool
any p [] -> false
any p (x:xs) 
 | p x = true
 | otherwise = any p xs
```

all :: (a -> Bool) -> [a] -> Bool

```
This should return true when all values are True when p.

Another useful function is zip:
``` haskell
zip :: [a] -> [b] -> [(a,b)]
zip (x:xs) (y:ys) = (x, y) : (zip xs ys)
zip _ _ = []
```
This is because `(x:xs)` in a pattern-match ensures there is at least an `x`.

A slightly more general version:

```haskell
zipWith :: (a -> b -> c) -> [a] -> [b] -> [c]
zipWith f (x:xs) (y:ys) = f x y : zipWith f xs ys
zipWith _ _ _ = []
```

We can define zip with zipWith
```haskell
zip xs ys = zipWith (\x y -> (x, y)) xs ys
```
...or more concisely
```haskell
zip = zipWith (\x y -> (x, y))
```
We may also know that: 
```haskell
(,) :: a -> b -> (a,b)
(,) x y = (x,y)
```
...so we have
```haskell
zip = zipWith (,)
```
We should also implement unzip
```haskell
unzip :: [(a,b)] -> ([a], [b])
unzip [] = ([],[])
unzip ((x,y):xys) = (x:xs,y:ys)
  where (xs, ys) = unzip xys
```
Another useful function on lists:
```haskell
concat :: [[a]] -> [a]
concat [] = []
concat (xs:xss) = xs ++ concat xss
```

Many recursive functions over lists are an example of a fold over that list:
```haskell
sum :: [Int] -> Int
sum [] = 0
sum (x:xs) = x + sum xs
```
Given a list `xs = [x1, x2, ..., xn] = x1 : x2 : ... : xn : []`

We may notice that `sum` tranforms the structure above with `+` instead.

Generalising this observation is called a `foldr` function:
```haskell
foldr :: (a -> b -> b) -> b -> [a] -> b
foldr f k [] = k
foldr f k (x:xs) =  f x (foldr f k xs)
```

With this, we have a shorter definition of sum:
```haskell
sum :: [Int] -> Int
sum = foldr (+) 0

product :: [Int] -> Int
product = foldr (*) 1

concat :: [[a]] -> [a]
concat = foldr (++) []

map :: (a -> b) -> [a] -> [b]
map f xs = foldr g [] xs
   where g :: a -> [b] -> [b]
         g x ys = f x : ys
```

There is also the concept of fold-map fusion:
```haskell
foldr f k . map g = foldr (f . g) k
```
We might use this in the following:
```haskell
any :: (a -> Bool) -> [a] -> Bool
any p xs = (or . map p) xs
```
...and we may define or as a foldr
```haskell
or :: [Bool] -> Bool
or xs = foldr (||) False
```
We would therefore write the following version of any:
```haskell
any' :: (a -> Bool) -> [a] -> Bool
any' p xs = (foldr (||) False . map p) xs
= (foldr(|| . p) False) xs
```

To prove the fold-map fusion law:
We must show for all xs that
```haskell
(foldr f k . map g) xs = (foldr (f.g) k) xs
Base case: []
LHS
(foldr f k . map g) []
= {(.)}
 (foldr f k (map g [])) []
 = {map}
 foldr f k []
 = {foldr}
 = k

 RHS

 Inductive case. Assume (foldr f k . map g) xs = (foldr (f . g) k) xs and prove that (foldr f k . map g) = (foldr (f . g) k) (x:xs)

 LHS (foldr f k . map g) (x:xs)
 = {.}
 foldr f k (map g (x:xs))
 = {map}
 foldr f k (g x : map g xs)
 = {foldr}
 f (g x) (foldr f k (map g xs))

 RHS
(foldr (f . g) k) (x:xs)
