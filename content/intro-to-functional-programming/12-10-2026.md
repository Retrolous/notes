# Lecture 4

Definining a monomorphic list of `ints`:

``` haskell
data ListInt where
  Empty :: ListInt
  Cons :: Int -> ListInt -> ListInt
```

We can now write, for example:
``` haskell
Empty :: ListInt
Cons 5 Empty :: ListInt
Cons 3 (Cons 5 Empty) :: ListInt

isEmpty :: ListInt -> Bool
isEmpty Empty = True
isEmpty (Cons x xs) = False
```

However, it would be better to have lists that work for any type. Therefore, lists are defined in the prelude like:

``` haskell
data [a] where -- where a is a polymorphic type
  [] :: [a]
  (:) :: a -> [a] -> [a]
```

`[3,4,5]` is syntactic sugar for `3 : 4 : 5 : []`
Therefore, to add something to the end, we have to traverse the entire list.

Anatomy of a list:
    `3 : 4 : 5 : []`
    (head) (tail)

So we have the following functions defined:
``` haskell
head :: [a] -> a
head (x:xs) = x

tail :: [a] -> [a]
tail (x:xs) = xs
```
...where `x` denotes the first element, and `xs` the remaining elements

These are dangerous because `head []` and `tail []` cause an error.

Instead:
``` haskell
isEmpty :: [a] -> Bool
isEmpty [] = True
isEmpty _ = False
```

Another definition:
``` haskell
isSingle :: [a] -> Bool
isSingle [x] = True
isSingle _ = False
```
Another dangerous function:
``` haskell
second :: [a] -> a
second [x,y] = y
second [x,y,z...]
```
We can use this but still dangerous:
``` haskell
second (x:y:zs) = y
```
But consider `[]` and `[x]`. 

Consider a function which adds all of a list's elements together:
``` haskell
sum :: [Int] -> Int
sum [] = 0
sum (x:xs) = x + sum xs
```

The length of a list:
``` haskell
length :: [a] -> Int
length [] = 0
length (x:xs) = 1 + length xs
```

The append function sticks two list together:
`[1,2,3] ++ [4,5,6] = [1,2,3,4,5,6]`

We define this using pattern matching:

``` haskell
(++) :: [a] -> [a] -> [a]
[] ++ ys -> ys
(x:xs) ++ ys  -> x : (xs ++ ys)
```

Suppose we have a list `xs` of k elements:

To define `take` and `drop` we do so with recursion:

``` haskell
take :: Int -> [a] -> [a]
take 0 _ = []
take _ [] = []
take n (x:xs) = x : take (n - 1) xs
```

``` haskell
drop :: Int -> [a] -> [a]
drop 0 xs = xs
drop _ [] = []
drop n (x:xs) = drop (n - 1) xs
```

The bang bang function is written `!!` and extract an element from a list e.g.

``` haskell
[3, 1, 4, 1, 5] !! 0 = 3
[3, 1, 4, 1, 5] !! 2 = 4

(!!) :: [a] -> Int -> a
(x:xs) !! 0 = x
(x:xs) !! n = xs !! (n - 1)
_ !! _ = error("keep yourself safe")
```

### Accumulating parameters

If we want to reverse a list:
``` haskell
reverse [3, 4, 5] = [5, 4, 3]

reverse :: [a] -> [a]
reverse [] = []
reverse (xs:x) = reverse xs ++ [x]
```

This has buns performance because consider:
```
reverse [x1, x2, x3, ..., x4]
= ((         ) ++ [x2]) ++ [x1]
```
...and `++` is defined recursively as well.

Better:
```
reverse' :: [a] -> [a]
reverse' xs = go xs []
  where 
    go :: [a] -> [a] -> [a]
    go [] ys = ys
    go (x:xs) ys = go xs (x : ys)
```

### Mapping
Sometimes we want to apply a function to a whole list:
e.g. transform all characters into number codes

``` Haskell
ord :: Char -> Int
ord 'a' = 97
...
```
We define map as follows:
``` Haskell
map :: (a -> b) -> [a] -> [b]
map f [] = []
map f (x:xs) = (f x) : (map xs)
```
